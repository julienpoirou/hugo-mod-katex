# Security policy

## Reporting a vulnerability
Please **do not** open a public issue.  
Contact: **julienpoirou@protonmail.com** (subject `[SECURITY]`).

Include:
- module version, OS, Hugo version, browser if relevant
- reproduction steps
- estimated impact


## Coordinated disclosure timeline
- We acknowledge your report within **72 hours** and provide an initial assessment within **7 days**.
- We keep you informed of remediation progress and aim to release a security fix within **90 days**, depending on severity and complexity.
- Please keep the vulnerability confidential while we investigate. We coordinate the public disclosure date with you after a fix is available.
- If the report is declined or cannot be reproduced, we explain the decision before closing the investigation.

## Supported versions
- Latest release + previous (security patches).
